<h1>Tic Tac Toe</h1>


<p>This is a simple implementation of the classic Tic Tac Toe game using Python. The game can be played by two players taking turns to mark their symbols (X and O) on a 3x3 grid.</p>

<h2> PS: This is a simple implementation for learning purposes. not optimized for performance or advance features.</h2>
